# MacLink 多功能助理改版

## 目標

手機交辦自然語言任務，Mac 的任務引擎查看狀態、使用工具、回報進度和結果；手機可中止、接手桌面及處理明確的批准。不能以幾個文字指令或開啟計算機代替完整驗收。

## 2026-09-26 參考來源

- https://github.com/openinterpreter/openinterpreter ：官方目前提供 Codex 相容協定、MCP、工具執行及 web/native QA。參考任務與工具分層，不複製品牌或將其宣稱為本 App 已具備的能力。
- https://github.com/browser-use/browser-use ：瀏覽器代理示範，適合参考網頁任務，但不能當作完整 macOS 桌面控制。
- 本機 Codex app-server --help 與 generate-json-schema 實際產生的協定：stdio 傳輸、initialize、turn/interrupt。介面屬 experimental，須固定版本相容檢查。

## 架構與目前進度

- 已接入本機 Codex app-server；使用者已同意使用登入帳號的雲端 Codex。Codex 任務內容會傳送至 OpenAI；原本本機 Ollama 助理是另一個入口。
- 手機已有任務清單、置頂順序、按工作目錄名稱分類、搜尋已載入任務、分頁、對話快照、送出與停止入口。送出到完成的真機完整鏈路尚未驗收。
- 已接單次命令批准卡，可允許一次或拒絕；已處理錯誤任務、重複回答與已解決請求。檔案變更批准、工具提問、串流工具進度仍未實作。
- 小秘書來電按鈕會為目前任務排入既有通知服務；排入成功不表示實際撥出或接通，仍受既有冷卻及每日上限限制。App 內即時語音尚未實作。
- CLI 的工具不等於桌面 Codex 所有工具；完整桌面操作、附件、模型切換、建立任務等仍需實作與驗收。
- TLS、私人網路、配對與操作批准要求繼續適用。

## 驗收

- 真機任務從送出到結果可追蹤，中斷連線後不重複執行。
- 執行時可以停止；批准等待不算完成；引擎退出會清楚顯示失敗。
- 至少完成一項網頁研究、一項檔案產出、一項跨 App 多步桌面操作，核對實際結果。
- 手機鍵盤退出、返回、重連及行動網路仍須真機驗證。
